# Scoop bucket for Orbit Actions

[Scoop](https://scoop.sh) bucket for [Orbit Actions](https://github.com/Goldingeng/Orbit-Actions), a fast radial (pie) menu launcher for Windows written in Rust.

```powershell
scoop bucket add orbit-actions https://github.com/Goldingeng/scoop-bucket
scoop install orbit-actions
```

Start the menu with `orbit-actions`, then open it with Ctrl+Space or Alt + left click. Menus and settings are kept when you run `scoop update orbit-actions`.

The manifest is updated automatically when a new release is published.

# Scoop-бакет для Orbit Actions

Бакет [Scoop](https://scoop.sh) для [Orbit Actions](https://github.com/Goldingeng/Orbit-Actions) - быстрого кругового меню для Windows, написанного на Rust.

```powershell
scoop bucket add orbit-actions https://github.com/Goldingeng/scoop-bucket
scoop install orbit-actions
```

Запустите меню командой `orbit-actions` и открывайте его через Ctrl+Space или Alt + левый клик. Меню и настройки сохраняются при `scoop update orbit-actions`.

Манифест обновляется автоматически, когда выходит новый релиз.
